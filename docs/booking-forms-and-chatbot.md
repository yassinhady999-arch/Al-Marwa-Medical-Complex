# نماذج الحجز والشات بوت

## التفعيل (مرة واحدة)

1. شغّل ملف `supabase/migrations/20261003120000_booking_forms_and_chatbot.sql` في Supabase ← SQL Editor ← Run. الملف آمن لإعادة التشغيل.
2. للردود بالذكاء الاصطناعي فقط: ضع مفتاح Anthropic باسم `ANTHROPIC_API_KEY` في متغيرات البيئة لدى الاستضافة. محليًا ضعه في ملف `.env` ثم أعد تشغيل `npm run dev`. وضع «اختيارات فقط» والرد من «الأسئلة والأجوبة» يعملان بدون أي مفتاح.

## نماذج الحجز — `/forms`

- **الحقول:** الاسم ورقم الجوال واختيار الموعد حقول أساسية لا تُحذف. يمكن إضافة البريد والجنس وتاريخ الميلاد والمدينة والملاحظات، أو أي حقل مخصص: نص، رقم، قائمة، اختيار من متعدد، مربع موافقة، تاريخ.
- **الإعدادات:** تحديد التخصصات والخدمات المتاحة، واختيار الطبيب من العميل أو تعيينه تلقائيًا للأقل انشغالًا، وفترة الحجز (حتى 60 يومًا)، وإظهار الأسعار، ورسالة التأكيد.
- **الرابط:** `https://<موقعك>/book/<رمز>`. إيقاف النموذج يوقف الرابط فورًا، وحذفه لا يحذف المواعيد التي حُجزت من خلاله.
- **كل حجز:**
  - يُنشئ موعدًا بحالة «بانتظار التأكيد» ومصدر «الموقع» في صفحة المواعيد.
  - يربط المريض برقم جواله (ينشئه إن لم يكن موجودًا).
  - يحفظ إجابات الحقول المخصصة في ملاحظات الموعد وفي تبويب «الحجوزات» بالنموذج.
  - يرسل إشعارًا للموظفين وحدث `appointment.created` إلى n8n.

### منع الحجز المزدوج

- **عند العرض:** الأوقات المعروضة هي المتاحة فعلًا فقط، وفق دوام الطبيب والاستراحة والمواعيد المحجوزة والوقت الحالي.
- **عند التأكيد:** تُعاد كل الفحوص داخل قاعدة البيانات. وإذا ضغط عميلان على نفس الوقت في نفس اللحظة، يُنفَّذ الحجزان واحدًا تلو الآخر لكل طبيب ويوم، فيحصل الثاني على «هذا الموعد لم يعد متاحًا».
- **إعادة الإرسال:** الضغط المزدوج أو إعادة المحاولة يعيد نفس الحجز ولا يُنشئ حجزًا ثانيًا.

### حدود الحماية

- رقم الجوال الواحد: 3 حجوزات قادمة كحد أقصى من النماذج.
- النموذج الواحد: 500 طلب يوميًا.

## الشات بوت — `/chatbot-training`

- **الرابط:** `https://<موقعك>/chat/<رمز>`. يوجد أيضًا زر لنسخ كود iframe لوضعه في موقعك، وزر «تجديد الرابط» يوقف الرابط القديم.

### طرق الرد

| الطريقة      | كيف تعمل                                                                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| اختيارات فقط | شبكة أزرار بدون أي نموذج: كل اختيار يرد على العميل ويمكن أن يتفرع منه اختيارات أخرى (حتى 8 مستويات و400 اختيار).                                          |
| ذكاء اصطناعي | العميل يكتب سؤاله ويرد Claude من معلومات العيادة الحية (الخدمات والأسعار والأطباء ومواعيد العمل والتواصل) ومن «الأسئلة والأجوبة» والتعليمات الإضافية فقط. |
| الاثنان معًا | يبدأ بالأزرار ويستطيع العميل كتابة أي سؤال.                                                                                                               |

### أنواع الردود في الشجرة

- رد نصي تكتبه أنت.
- ردود تُبنى تلقائيًا من البيانات: الخدمات والأسعار (اختياريًا لتخصص واحد)، الأطباء، مواعيد العمل، الموقع والتواصل (مع زري اتصال وواتساب)، حجز موعد (يفتح نموذج الحجز المختار في الإعدادات).
- رابط خارجي.

### بدون مفتاح أو بعد الحد اليومي

يرد البوت على السؤال المكتوب بأقرب إجابة من «الأسئلة والأجوبة»، وإن لم يجد يعرض رسالة «لا أعرف» مع القائمة.

### الذكاء الاصطناعي

- **النموذج:** الافتراضي `claude-opus-5-5`، ويمكن اختيار `claude-sonnet-5-5` أو `claude-haiku-4-5` من الإعدادات.
- **التكلفة:** الحد اليومي لعدد أسئلة الذكاء الاصطناعي (300 افتراضيًا) يحمي فاتورة الـ API لأن الرابط عام.
- **السلامة:** البوت لا يشخّص، ويوجّه الحالات الطارئة إلى 997، ولا يخترع معلومات غير موجودة.

### تعليم البوت

تبويب «أسئلة العملاء» يسجل ما كتبه العملاء. الأسئلة «بدون إجابة» تُضاف إلى «الأسئلة والأجوبة» بضغطة واحدة.

## واجهة الشات للمطورين

| الطلب                      | الوصف                                                                                                                                                                        |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /api/public/chatbot`  | يعيد `{ "ai_configured": true \| false }`                                                                                                                                    |
| `POST /api/public/chatbot` | `{ slug, session_id, messages: [{role, content}] }` ← `{ answer }`. الأخطاء: `ai_not_configured` (503)، `quota_exceeded` (429)، `ai_disabled` (403)، `bot_unavailable` (404) |

الصفحات العامة تستخدم فقط دوال `get_public_*` و`submit_public_booking` و`consume_chatbot_ai_quota` و`log_chatbot_exchange`. أما الجداول نفسها فمحمية بالكامل ولا يقرؤها إلا الموظفون.
